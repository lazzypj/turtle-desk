# Turtle Desk

Phone app for the private Turtle-strategy scanner. The page holds no data or keys; it reads your private repo with a GitHub token saved only in your browser.

Open: https://lazzypj.github.io/turtle-desk/

## Proposal Desk

https://lazzypj.github.io/turtle-desk/proposals/ — viewer for the private proposal-tracker repo. Same model: no data here, read-only token kept in the browser.
